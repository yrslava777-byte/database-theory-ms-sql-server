## Учебные материалы

[Презентации преподавателя](materials/) хранятся отдельно от выполненных работ.

## Структура

- `practical/` — 6 практических работ, каждая в отдельной папке с описанием и отчётом.
- `homework/` — 3 домашних задания с описаниями и выполненными работами.
- `materials/` — 4 учебные презентации в форматах PPTX и PDF.

## Просмотр

Все девять отчётов доступны в PDF для просмотра прямо на GitHub. Word-файлы сохранены рядом для редактирования. README содержит тему, задание и описание закрепляемых навыков. Учебные презентации хранятся отдельно в materials.

Репозиторий содержит работы из предоставленной папки. Даты занятий и история выполнения задним числом не восстанавливались. По мере выполнения новых заданий добавляйте отдельную папку с README и ссылку в навигацию.
