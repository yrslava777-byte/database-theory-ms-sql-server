# Практическая работа №1. Выбор хранилищ для образовательной платформы

**Тема:** Выбор хранилищ для образовательной платформы.

**Задание:** Сопоставить сущности, операции и нагрузку с подходящими хранилищами; определить источник истины, кэширование и синхронизацию.

**Закрепляемые знания и навыки:** Анализ нагрузки, ACID, согласованность данных, PostgreSQL, Redis, Elasticsearch и ClickHouse.
