# Практическая работа №5. Программируемые объекты базы киберспортивных команд

**Тема:** Программируемые объекты базы киберспортивных команд.

**Задание:** Реализовать и проверить объекты базы для игроков и команд, включая регистрацию и переходы между командами.

**Закрепляемые знания и навыки:** Хранимые процедуры, представления, триггеры и проверки бизнес-правил. Решения и результаты сохранены скриншотами в документе.
