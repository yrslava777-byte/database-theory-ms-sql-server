# Домашнее задание №3. Аналитика БД

**Тема:** Анализ запросов с помощью SQL Server Profiler.

**Задание:** Создать и заполнить TrainingDB, выполнить три запроса, собрать трассы и планы, добавить индексы и сравнить результаты до и после.

**Закрепляемые знания и навыки:** SQL Server Profiler, Duration, Reads, CPU, планы выполнения, блокировки и индексы.

## Файлы

- [Выполненное задание со скриншотами](Домашнее%20задание%203.docx).

Работа выполнена на SQL Server 2025. Каждый запрос запущен трижды до и после создания индексов. В отчёте приведены код, фактические замеры и выводы.
